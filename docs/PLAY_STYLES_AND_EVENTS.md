# 플레이스타일과 시즌 중 전환점

2026-11-06. 매년 능력치를 무작위로 교체하는 기능을 폐기했다. 생성 때 고른 집중 능력을 유지하며, 시즌 도중 가끔 찾아오는 제안을 보고 플레이어가 변경 여부를 결정한다.

## 조사와 게임 적용

MLB의 [포심 패스트볼](https://www.mlb.com/glossary/pitch-types/four-seam-fastball), [싱커](https://www.mlb.com/glossary/pitch-types/sinker), [체인지업](https://www.mlb.com/glossary/pitch-types/changeup), [슬라이더](https://www.mlb.com/glossary/pitch-types/slider) 설명에서 구속·코스·구종 변화·완급이라는 투구 접근을 참고했다. 타자는 [출루율](https://www.mlb.com/glossary/standard-stats/on-base-percentage)과 [순수 장타율](https://www.mlb.com/glossary/advanced-stats/isolated-power)을 참고해 출루와 장타의 차이를 구분했다.

아래 6개씩의 분류와 수치는 게임 설계다. MLB가 공식으로 정한 6분류가 아니다. 구종별 물리나 땅볼 확률을 새로 구현한 것은 아니며, 기존 시뮬레이션이 사용하는 능력치와 이후 성장 대상을 통해 플레이에 반영한다.

| 투수 스타일 | 접근 | 우선 성장 |
| --- | --- | --- |
| 파워피처 | 빠른 공과 변화구로 헛스윙 유도 | 구속·변화구 |
| 제구형 | 코너 공략과 볼넷 억제 | 제구·정신력 |
| 변화구형 | 움직임으로 타이밍 공략 | 변화구·제구 |
| 땅볼 유도형 | 낮은 코스 중심 | 제구·변화구 |
| 완급 조절형 | 구속 차 활용 | 변화구·정신력 |
| 이닝이터 | 긴 이닝을 위한 지속력 | 체력·제구 |

| 타자 스타일 | 접근 | 우선 성장 |
| --- | --- | --- |
| 교타형 | 정확한 타격과 안타 | 컨택·선구안 |

| 올라운더 | 정확성과 장타력의 균형 | 컨택·파워 |

## 이벤트 규칙

- 시즌별 42% 확률로 제안 하나를 계획한다. 발생하지 않는 시즌도 있다. 발생 시점은 시즌의 약 25~80% 구간이다.
- 제안 중 70%는 현재와 다른 스타일, 30%는 다른 집중 능력이다. 이 확률은 조정 가능한 게임 수치다.
- 자동 진행은 해당 라운드를 저장하고 멈춘다. 별도 화면에서 현재/제안 스타일, 성장 대상, 능력치 전후를 비교한다.
- 수락하거나 유지할 수 있다. 결과를 확인해야 시즌을 이어갈 수 있다. 유지하면 능력치와 집중 능력이 보존된다.
- 스타일 수락 시 새 우선 능력에 최대 +3/+2를 배분한다. 다른 능력에서 각 최대 2를 옮겨 총합을 보존한다. 1~99 범위를 넘지 않는다. 베테랑을 신인 기본 능력치로 초기화하지 않는다.
- 이후 성장도 새 스타일을 따른다. 집중 능력 변경 제안은 누적 능력치를 즉시 바꾸지 않는다.
- 생성 때는 스타일과 집중 능력을 직접 고른다. 스타일 선택이 기본 집중 능력을 제안하지만, 다른 능력을 선택할 수 있다.
- 발생 여부·제안·수락 결과를 저장한다. 새로고침으로 제안을 뽑거나 같은 전환을 중복 적용할 수 없다.
- 기존 스타일 번호 0~2의 의미를 유지한다. 예전 연간 변경 함수는 기존 호출 호환만 남기며 아무것도 변경하지 않는다.
