고교·U18 마크는 학교 선택 카드·현재 선택·선수 미리보기·홈·선수 정보·순위표에 표시한다. 대학 마크는 학교 선택 단계의 검색·페이지 기능이 있는 대학 야구부 도감에서 확인한다. 이번 변경은 대학 진학이나 대학 리그를 추가하지 않는다.

협회에서 공통 카메라 기본 이미지를 사용하는 명지BC(U-18), 부원고야구단, 상우고야구단, 세종BC(U-18), 수원야구단(U-18), 창녕SC(U-18)는 실제 마크로 오인하지 않도록 자체 이름 배지를 표시한다. 이미지가 로드되지 않아도 같은 방식으로 대체한다. 학교를 바꾸면 새 마크 로딩을 다시 시도한다.

- 개별 팀 상세 페이지·원본 이미지 URL·조회일·SHA-256·파일 크기는 `public/schools/sources.json`에 기록했다.
- 실제 표시 경로는 `src/data/school-marks.json`, 대학 목록은 `src/data/universities.json`이다.
