## 발견하고 수정한 밸런스 문제

초기 10커리어 표본은 모두 MVP 0회였다. 원인은 사용자 지명타자의 자동 교체·수비 위치와 타순의 결합·불펜 마지막 투수에게 집중된 이닝·선발 체력이 소화 이닝에 반영되지 않는 구조와 수상 지수였다.

타순을 수비 위치와 분리하고 타격 능력에 따라 중심 타순을 배정했다. 강한 주전 지명타자는 자동 대타로 빼지 않는다. 불펜 순서를 순환시키고 선발 체력에 따라 투구 한도를 계산한다. 순수 구원의 과다 이닝이 수상 지수를 왜곡하지 않도록 보정한다. 이 보정은 원래 경기 기록을 바꾸지 않는다. MVP 지수는 실제 WAR를 재현한 값이 아니다.

아래는 수정 뒤 엔진 시뮬레이션 10커리어다. 각 커리어는 고교 3년과 프로 20시즌을 거쳐 38세에 은퇴했다. 시드 1~10, 역할 번갈아 선택, 가장 낮은 능력치 훈련, 컨택/제구 집중 육성, 매년 정상 아이템 1개 사용과 계약 선택을 이용했다. 저장·수상·능력치를 강제로 고정하지 않았다. 브라우저 사용자 플레이 10회를 의미하지 않는다.

추가 공격형 지명타자 빌드는 정상 규칙으로 시즌 MVP **12회**를 달성하고 2048년 전설 칭호를 받았다. 시드 3, 컨택 집중, 컨택 75까지 훈련 후 파워 99·선구안 순으로 훈련한 경로다. 선수 능력치 주입·수상 강제 없이 진행한 별도 테스트다. 모든 커리어가 12회 달성을 보장받는 구조는 아니다. 테스트 원시 결과는 로컬 artifacts/balance-careers.json, artifacts/mvp-build.json에 있다.

명성은 정상 출전·개인상·MVP·우승·국제대회 성과에서 증가하며, 제안 연봉과 1회 협상에 반영된다. 이는 경기 결과나 MVP를 직접 보정하지 않는다.

## 검증

- 타입 검사와 정적 빌드 통과.
- 엔진/저장 테스트 62개 통과.
- Chromium 브라우저 17개 시나리오 통과. 기본 경로와 /diamond-road/ 배포 경로에서 확인했다.
- 100개 시드의 첫 프로 시즌, 타자/투수 각각 고교부터 은퇴까지의 2커리어 회귀 검사 통과.
- 별도 육성 10커리어와 공격형 MVP 12회 1커리어 완주 검사 통과.
- 320px 생성·홈·준비, 1440px 생성, 학교 검색·뒤로가기·키보드·필수 훈련·아이템·국제대회·계약·트레이드·방출·은퇴·이전 저장을 검사했다.

## 실용적 한계

18인 선수단에 맞춘 경기·투수 운용 모델이다. 실제 야구 규약 전체, 군 복무, FA 보상선수·구단 영입 한도·샐러리캡, 실제 경기 통계 재현을 포함하지 않는다. 건강·피로·예전 수동 경기 관련 저장 필드는 구버전 복구를 위한 호환용으로만 남는다. 개인 수비 실책·보살·자살 통계는 없다.

현재 사용자 요청의 기능 목록은 구현했으며, 실제 모바일 하드웨어·Safari/Firefox·다수 사용자 재미 조사는 수행하지 않았다. 브라우저 테스트는 Chromium의 지정 뷰포트를 사용했다. 게임 밸런스는 측정한 시드와 육성 전략의 범위에서 검증했다.
