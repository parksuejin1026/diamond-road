## 다음에 할 일 — 아직 완료했다고 설명하지 말 것

1. 실제 플레이 피드백으로 홈 → 시즌 시작, 상점 구매, 스타일 수락/유지, 은퇴 취소, 과거 시즌 조회의 불편을 점검한다. 320/390px과 데스크톱, 긴 선수명·긴 계약 이력도 확인한다.
2. 스타일별 다수 시드 장기 표본을 모아 성적과 MVP 난도 편차를 비교한다. 이번 장기 검사는 타자·투수 각 한 커리어의 완주 안정성을 확인한 것이며, 12개 스타일 전체의 균형을 확정한 검사가 아니다.
3. 구종별 물리·땅볼 확률 같은 스타일 고유 경기 규칙을 더 넣을지 정한다. 현재는 기존 능력치 시뮬레이션에 초기 배분·전환 재배분·성장 방향으로 반영한다.
4. 학생 시절 중도 은퇴의 부분 시즌, 학생 때의 스타일 전환 등 회고에서 더 자세히 보여줄 항목을 검토한다. 현재 학생 통산은 완료한 학년 기록 기준이다.
5. 새 UI에서 모션 화면·본인 명장면·계약·국제대회 화면의 시각적 일관성을 실제 플레이로 점검한다. 기존 v4 원화/프레임 재생은 유지했다.
6. 대학 조기 프로 도전·학제 다양화는 별도 후속 범위다. 현재 대학 4년 후 드래프트를 지원한다.

새 기능을 시작하기 전에 사용자에게 우선순위를 확인한다. 저장 파일과 은퇴 아카이브를 보존하고, 이전 문서의 ‘매년 랜덤 변경’이나 ‘SVG 부위 회전 애니메이션’을 현행 규칙으로 되돌리지 않는다.
