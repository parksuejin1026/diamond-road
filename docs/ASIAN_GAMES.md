# 아시안게임 구현

브랜치: `feature-asian-games`. 이 기능은 아직 공개 Pages에 배포하지 않았다.

후속 전체 완성 작업에 함께 포함했다. 건강·피로 제거에 따라 선발에서 부상 상태는 더 이상 제외 조건이 아니며 2군 제외는 유지한다. 화면은 시즌의 대회 탭 및 기록의 대표팀 탭에서 확인한다. 배포 상태는 저장소 main의 최근 성공한 실행을 기준으로 한다.

## 대회 구성

[KBO 2026 아시안게임 안내](https://www.koreabaseball.com/Schedule/International/AsianGames/Main2026.aspx)와 [일본 대표팀 공식 대회 안내](https://www.japan-baseball.jp/jp/team/amateur/2026/asiangames/overview.html)의 참가국·진행 방식을 참고했다. 실제 선수 명단이나 실제 경기 결과를 복제하지 않는다.

게임에서는 2026년을 시작으로 4년마다 대회를 생성한다. 미래 실제 개최 일정·개최지·선발 기준을 예측한 설정은 아니다. KBO 시즌 자동 진행이 끝날 때 함께 정산하며 별도의 조작이나 중간 선택을 요구하지 않는다. 고교 선수의 대표팀 참가와 고교 시즌 대회 정산은 이번 범위에 포함하지 않는다.

- A조: 일본·중국·필리핀·팔레스타인.
- B조: 대만·대한민국·홍콩·태국.
- 각 조 단일 리그 12경기 후 상위 2개국은 슈퍼라운드, 하위 2개국은 순위 결정전으로 진출한다.
- 같은 조에서 이미 만난 상대의 결과는 이어받고 다른 조 2개국과 대결한다. 슈퍼라운드 4경기와 하위 순위 결정전 4경기다.
- 슈퍼라운드 1·2위는 금메달전, 3·4위는 동메달전을 치른다. 총 22경기, 한 팀은 최대 6경기다.

## 게임 선발 기준

가상 KBO 선수의 능력과 해당 시즌 성적을 반영한다. 기본 후보는 19~25세이며 26~29세 중 최대 3명을 와일드카드 후보로 포함한다. 부상·2군 상태의 선수는 제외한다. 타자·투수 각각 12명, 총 24명을 뽑는다. 젊은 선수 풀이 모자랄 때를 대비해 가상 아마추어 후보를 추가한다. 실제 대표팀의 연령 예외·프로 연차 기준·포지션별 배분·소속 구단별 인원 제한을 완전히 재현한 선발은 아니다.

미선발 선수에게도 사유와 대한민국의 대회 결과를 남긴다. 국가의 메달과 사용자의 개인 메달은 구분한다. 사용자가 선발됐을 때만 개인 대회 기록과 명성 보상을 부여한다. 병역 제도·FA 등록 기간 특례·현금 보상은 연계하지 않는다.

## 경기와 기록

기존 타석·주루·수비·투수 교체 엔진을 별도 대표팀 선수단과 기록 저장소에서 실행한다. 상대 선수는 국가별 게임 능력치로 생성한 가상 선수다. 24명 전체가 등판·출전하는 것은 아니며 기존 선발·교체 루틴을 활용한다. 로테이션은 각 국가의 대회 경기 수를 기준으로 돌아간다.

12회 동점이면 실제 타석 시뮬레이션을 이어가 승자를 가린다. 승부치기·콜드게임·투구 수 제한은 미구현이다. 순위가 같으면 득실차·득점·국가 ID 순으로 결정하며 공식 TQB 규정과 다르다.

대회는 독립된 시드 난수를 사용한다. KBO 정규·포스트시즌 기록, 성장 기록, 계약 등록 일수와 클럽 난수 상태를 대회 경기로 덮어쓰지 않는다. 대회 명성 보상은 계약 제안 금액에 반영될 수 있다. KBO 시즌 MVP와 국제대회 메달은 별도로 취급한다.

`asianGames`에 연도·선발 여부/사유·대표팀 명단·경기 결과·순위/메달·개인 기록·명성 보상을 저장한다. 같은 연도에 다시 호출하면 기존 결과를 반환하여 중복 경기·보상을 막는다. 다음 시즌에도 과거 대회 기록은 유지된다. 이 필드가 없는 이전 저장은 그대로 불러오며, 종료된 과거 대회를 소급 생성하지 않는다. 손상된 대회 기록은 직전 저장 복구 대상으로 처리한다.

## 화면과 검증

시즌 탭에서 올해 대회 결과, 개인 성적, 대한민국 경기 결과와 최종 명단을 확인한다. 기록 탭에는 선발·메달·성적 이력이 남는다. 메달 아이콘은 직접 작성한 픽셀 SVG다.

타입 검사·정적 빌드·엔진 테스트 51개가 통과했다. 대회 22경기·개인 기록·결정성·KBO 기록 및 난수 분리·중복 정산 방지·미선발·연령·고교 제외·저장 복원을 검사했다. 기존 브라우저 검사 9개 통과 후 대표팀 타자/투수 화면과 별도 기록 복원 검사 2개도 통과했다. 저장 검증 보강 후 해당 테스트 8개를 재실행해 통과했다.
