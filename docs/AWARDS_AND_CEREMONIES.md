# 개인상 기준과 수상 연출

2026-11-06. 시즌 MVP·골든글러브 수상 연출 요청과 한국시리즈 MVP·야구판 발롱도르 기준 질문에 대한 기록이다.

사용자 결정: 시즌 MVP가 발롱도르에 해당하는 큰 시상식 역할을 맡는다. 한국시리즈 MVP는 개인 수상 이력으로 표시한다. 별도 종합상은 만들지 않는다. 수상별 아이콘을 시즌·개인 기록·은퇴 트로피에 연결했다.

## 현재 게임과 추천 방향

현재 시즌 MVP는 `calculateAwards`의 정규시즌 기록 점수로 결정한다. 타자의 안타·루타·볼넷·타점·득점·타수·삼진, 투수의 아웃·탈삼진·자책·승리와 작은 팀 승수 보정을 사용한다. 우승, OVR, 명성으로 수상을 강제하지 않는다. 실제 기자단 투표나 WAR를 구현한 것은 아니다.

현재 골든글러브도 포지션별 기록과 게임용 자격 기준을 사용한다. 실제 후보 자격과 미디어 투표 전체를 재현하지 않는다. 포스트시즌 우승·본인 명장면과 시즌 MVP를 같은 상으로 설명하지 않는다.

한국시리즈 MVP는 한국시리즈가 시작되기 직전과 끝난 뒤의 선수별 기록 차이를 구해 그 시리즈 성적만 비교한다. 우승팀의 실제 출전 선수 중 타자는 안타·장타·볼넷·타점·득점과 타격 아웃, 투수는 아웃·탈삼진·자책·피안타·볼넷으로 게임용 기여 점수를 계산해 1명을 선정한다. 동점은 선수 ID로 일관되게 처리한다. 준플레이오프·플레이오프·정규시즌 기록과 OVR·명성은 이 점수에 넣지 않는다. 실제 기자단 투표·WAR·승리확률 기여도를 재현한 것은 아니다.

선정된 상은 리그 수상 목록과 본인의 연도별 시즌 스냅샷에 남긴다. 한국시리즈 MVP는 큰 시상식을 열지 않고 시즌 MVP 12회 목표에도 합산하지 않는다. 과거 저장은 당시 한국시리즈 선수별 기록이 남아 있지 않아 수상을 소급해서 만들지 않는다.

추천은 우선 **시즌 MVP를 이 게임의 발롱도르에 해당하는 최상위 개인상으로 연출**하는 것이다. KBO 중심의 경쟁 선수단에서 세계 최고상이라는 이름을 새로 붙이면 세계 각 리그와의 비교가 구현돼 있다는 오해와 기존 상의 중복이 생긴다.

별도 종합상이 필요하다면 다음은 제안할 수 있는 게임 설계다. 아직 적용한 규칙이 아니다.

- 정규시즌 개인 활약 70%, 포스트시즌 개인 활약 20%, 국제대회 개인 활약 10%를 출발점으로 검토한다. 실제 발롱도르의 공식 비율이 아니다.
- 서로 단위가 다른 타자·투수 기록을 그대로 더하지 않고, 리그 수준·출전량·포지션을 고려한 비교 가능한 점수부터 설계한다. 현재 MVP 점수를 그대로 세계 최고상 점수로 재사용하지 않는다.
- 우승은 필수 조건으로 두지 않는다. 팀 트로피의 보정은 작은 상한을 두고, 실제 본인 출전·활약이 없는 우승이나 대표팀 메달로 큰 점수를 주지 않는다.
- 포스트시즌·국제대회에 못 나갔거나 대회가 없는 해의 배점 처리를 먼저 정한다. 출전 기회의 차이와 작은 표본의 높은 타율·낮은 ERA가 결과를 압도하지 않게 한다.
- 명성·연봉·OVR만으로 받는 상을 피한다. 측정하지 않는 페어플레이·개인 수비 통계를 만들어내지 않는다.
- 후보 순위와 실제 수상을 구분하고, 수상 화면에는 기록에 근거한 선정 이유를 보여준다.

한국시리즈 MVP는 위 게임용 기록 지수로 구현했다. 결정적 플레이의 추가 가중치는 아직 넣지 않았다. 우승만 했다고 사용자에게 자동 지급하거나 정규시즌 기록으로 대신 결정하지 않는다.

## 참고 연출과 구현

참고 게임은 [벤치에서 발롱까지](https://kickru.com/)다. 이전 실제 플레이의 `run-2-ballon-74.png`에서 결산 위로 등장하는 무대, 조명, 트로피를 든 선수, 건너뛰기를 확인했다. 같은 수상 구간의 화면 기록에는 첫 수상 안내·선수명·해당 활약·확인 동작이 남아 있다. 이번 세션에서 새 발롱도르 수상까지 플레이한 것은 아니다. 시작 화면도 재방문했으나 실제 수상 연출에 대한 근거는 이전 수상 캡처와 화면 기록이다. 원본 이미지·캐릭터·코드를 제품에 복사하지 않는다.

구현한 야구 시상식:

- 별도 수상 화면에 커튼·스포트라이트·선수의 기존 원화 프레임·MVP 컵 또는 황금 글러브·색종이·수상명·시즌 성적을 표시한다.
- 약 5.2초 연출, 즉시 건너뛰기, 다시 보기, 결과 확인을 제공한다. 건너뛰기는 수상 확인이나 데이터 지급을 대신하지 않는다.
- 본인에게 확정된 현재 시즌 MVP·골든글러브만 표시한다. 공동 수상 시 각각 확인한다. 다른 선수 수상·후보·학생 시상으로 이 연출을 발생시키지 않는다.
- 기존 저장의 연도별 확인 키를 사용해 새로고침 뒤 미확인 상부터 이어간다. 능력치·현금·수상 자체는 다시 지급하지 않는다.
- 마지막 시즌에 바로 은퇴하는 경우에도 수상을 확인한 뒤 회고로 간다.
- `prefers-reduced-motion`에서는 커튼·색종이·선수 동작을 생략하고 결과와 확인 버튼을 즉시 제공한다.

기존 시즌 MVP·골든글러브 선정 공식과 시즌 MVP 12회 목표는 변경하지 않는다. 별도 종합상을 신설하지 않는다.

## 상별 아이콘

자체 SVG로 시즌 MVP 금색 컵, 골든글러브 황금 장갑, 한국시리즈 MVP 은색 별 배지, 타격왕 배트·공, 홈런왕 배트·별, 타점왕 배트·진루 표시, 다승왕 승리 표시, 탈삼진왕 야구공·강조선, 평균자책점 1위 야구공·타깃, 리그 우승 컵을 제공한다. 기타 수상은 공통 메달로 표시한다. 공식 KBO 트로피 복제나 외부 이미지 자산이 아니다.

같은 아이콘을 시상식·시즌 총평·리그 개인상·연도별 개인 기록·은퇴 트로피에서 사용하며, 이름과 접근성 레이블을 함께 제공한다. 골든글러브 포지션 약자는 사용자에게 한글 포지션명으로 표시한다.

## 검증

상별 아이콘·한국시리즈 MVP 후속 변경: 엔진·저장 116개와 타입 검사 통과. `/diamond-road/` 빌드 및 수상 화면 5개 검사 통과. 우승팀의 실제 출전 여부, 타자/투수 선정, 정규시즌 수상 목록 분리, 시즌 MVP 목표 제외, 시즌·개인 기록·은퇴 회고 아이콘 표시를 확인했다. 320px·1440px 트로피 화면을 직접 확인했다. 기존 전체 57개 브라우저 시나리오에서도 각 동작의 성공을 확인했고, 종료 대기 중인 테스트 서버는 정리했다. 공개 배포는 하지 않았다.

- 타입 검사, 엔진·저장 검사 113개 통과.
- `/diamond-road/` 정적 빌드 및 전체 Chromium 검사 56개 통과. 이후 추가한 자동 연출 완료·저장 실패 보존 검사 1개도 통과.
- 320px·1440px에서 MVP와 골든글러브 순차 확인, 새로고침, 건너뛰기, 다시 보기, 중복 지급 방지를 검사했다. 마지막 시즌 은퇴와 모션 줄이기도 검사했다.
- MVP·골든글러브 화면 스크린샷을 직접 확인했다. 수상 데이터는 화면 검사용 예시를 주입했으며, 실제 게임 플레이에서 자연 수상한 결과로 설명하지 않는다.
- 저장 실패를 주입해 확인 키가 남지 않고 수상 화면이 유지되는 것을 확인했다. 회복 후 새로고침해 같은 미확인 수상을 다시 볼 수 있다.
- 공개 배포는 하지 않았다.
