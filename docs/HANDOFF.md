## 최신: 시즌 중 전환점·스타일·은퇴·UI 개편

아래 과거 기록의 ‘매년 랜덤 집중 변경’은 폐기했다. 현재 규칙과 조사 출처는 [PLAY_STYLES_AND_EVENTS.md](PLAY_STYLES_AND_EVENTS.md), 화면 설계는 [UI_REDESIGN_V5.md](UI_REDESIGN_V5.md)에 있다.

- 투수·타자 각각 6개 스타일. 기존 0~2 번호를 보존하며, 생성 집중 능력을 직접 선택한다. 시즌 중 확률 제안 → 전후 능력치 비교 → 수락/유지 → 결과 확인 순서다. 수락한 스타일은 누적 능력치를 초기화하지 않고 재배분하며 이후 성장 방향에도 반영한다.
- 연간 랜덤 변경 버튼을 제거했다. 이벤트 발생 여부·시점·결과를 저장해 재접속으로 재추첨하지 않는다. 자동 진행은 제안에서 정지한다.
- 은퇴는 native dialog 확인을 거쳐 `/legacy/` 전용 회고로 이동한다. 5개 장에서 통산·최고 시즌·학생 기록·연대기·수상·대표팀·구단·계약·실제 입금 수입을 살펴보고 새 선수 생성도 확인한다. 아카이브를 보존한다.
- 성장/상점과 경기 화면 분리, 다음 행동과 진행 단계 표시, 넓은 화면의 왼쪽 메뉴·모바일 하단 메뉴, 읽기 쉬운 본문, 스크롤 중 진행 버튼 접근을 적용했다.
- 107개 엔진·저장·재생 검사와 타입 검사·배포 경로 빌드 통과. 새 스타일의 제안을 수락하는 타자·투수 장기 검사 2개에서 각각 고교 3년 → 프로 20시즌 → 38세 은퇴를 완료했다. 이 표본을 스타일 전체의 난도 균형이 검증됐다는 의미로 해석하지 않는다.
- 은퇴 시 이벤트가 NONE인 저장을 RESOLVED로 바꿔 저장 검증이 실패하는 문제를 수정했다. 모달의 Tab 순환과 Escape 취소·원래 버튼 포커스 복귀를 검증한다. 모바일 패널 높이가 콘텐츠만큼 늘어나 화면 밖을 잘라내던 문제도 수정했다.

이전 애니메이션 v4 원화·재생 방식은 유지한다. 이번 스타일은 능력치 기반이며 구종별 물리나 독립된 땅볼 확률 시스템을 새로 구현했다고 설명하지 않는다.
