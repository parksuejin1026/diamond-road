## 사용성과 회고 수정

- 홈은 완료 시즌 통산 대신 현재 리그의 확정 경기 성적을 보여준다. 통산 기록은 기록 탭에서 확인한다.
- 현재 출전 역할·플레이스타일·집중 육성 능력을 함께 표시한다.
- 320px에서 긴 선수명 때문에 시즌 준비 버튼이 첫 화면 아래로 밀렸다. 다음 행동 버튼을 설명보다 앞에 배치해 접근을 개선했다.
- 학생 때 시즌 도중 은퇴한 경우 현재 학년의 확정 경기 기록을 학생 통산과 연대기에 포함한다. 완료 학년과 같은 연도는 다시 합산하지 않는다. 프로 통산에 섞지 않고, 학년 결산·수상·성장 결과를 새로 만들지 않는다.
- 학생 시절의 스타일 전환을 연대기에 표시한다. 저장 형식과 원본 저장 데이터는 변경하지 않는다.

## 스타일 비교 방법

`npx vitest run --config vitest.stress.config.ts stress/style-samples --maxWorkers=6`

12개 스타일마다 시드 11·29·47을 사용한다. 동일 고교, 고교 3년 → 프로 20시즌 → 38세 은퇴를 진행한다. 스타일/집중 변경 제안은 거절하고, 첫 계약 제안·국제대회 참가·매년 구매 가능한 가장 비싼 상점 상품을 선택한다. 능력치나 수상을 주입하지 않는다. 상품 선택은 성능 최적화 전략이 아니므로 모든 육성 전략을 대표하지 않는다.

세 시드의 소규모 진단 표본이다. 경기 결과와 계약·출전 기회까지 스타일에 따라 달라지므로 스타일 자체의 인과 효과나 전체 밸런스를 확정하지 않는다. 특히 수비·출루·이닝 소화 같은 역할의 가치와 시즌 MVP 횟수는 같은 지표가 아니다.

원시 결과는 무시된 로컬 `artifacts/style-balance-HITTER-0.json`부터 `artifacts/style-balance-PITCHER-5.json`까지 보관한다. 각 결과에 통산 성적·비율·최고 OVR·MVP·시즌별 기록과 실행 조건을 남긴다.
