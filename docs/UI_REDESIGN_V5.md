# 커리어 UI 개편

2026-11-06. 기준은 ‘현재 상태와 다음 행동을 빨리 이해하고, 중요한 선택을 실수 없이 마치는 것’이다. 모든 내용을 한 화면에 쌓지 않는다.

## 적용한 변경

| 기존 불편 | 적용 |
| --- | --- |
| 홈에서 다음 행동과 긴 목표가 경쟁 | 단계 표시와 다음 행동을 우선 배치하고 장기 목표는 펼쳐 보기로 이동 |
| 상점·성장·경기 정보가 뒤섞임 | 시즌을 경기 진행 / 성장·상점 / 대회 / 진로로 분리 |
| 스크롤 끝에서 진행 버튼 탐색 | 시즌 진행 버튼을 화면 아래에 고정하고 중단·저장 제공 |
| 데스크톱에서도 모바일 하단 메뉴 사용 | 넓은 화면은 왼쪽 메뉴, 모바일은 하단 메뉴 |
| 작은 픽셀 글꼴로 긴 설명 읽기 어려움 | 제목의 게임 분위기는 유지하고 본문·금액·버튼은 가독성 중심 글꼴 |
| 은퇴 버튼 오조작 우려 | 선수 → 커리어 관리에 배치하고 전용 확인 모달 제공 |
| 브라우저 기본 확인창 | 게임 색상·선수 정보·복귀 불가 설명·취소/확정 버튼을 담은 모달 |
| 은퇴 기록이 일반 플레이 화면에 섞임 | `/legacy/` 전용 화면과 5개 회고 장으로 분리 |

은퇴 클릭 때 뜨는 창은 **확인 모달/다이얼로그**다. 잠깐 나타났다 사라지는 알림인 토스트와 구분한다. [W3C 모달 대화상자 지침](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)을 참고해 native dialog를 사용하고, 취소 버튼에 초기 포커스, Escape 취소, 닫힌 뒤 원래 버튼으로 포커스 복귀를 적용했다. 저장 실패 시 모달 안에서 오류를 보여주며, 성공 전에 닫지 않는다.

## 은퇴 회고

1. 커리어 요약: 최고 OVR, 우승, MVP, 개인상, 주요 통산 성적, 실제 출전한 최고의 시즌.
2. 통산 기록: 프로 성적 합계와 시즌별 표, 학생 야구 별도 합산. 타율·ERA 등은 합산한 분모로 다시 계산한다.
3. 연대기: 고교·대학 성장, 프로 시즌, 스타일 전환과 복무 기록.
4. 트로피: 프로 우승·개인상과 대표팀 결과.
5. 구단·계약: 실제 뛴 구단, 계약·정산 내역, 장부에 입금된 수입. 미지급 보장액을 수입으로 계산하지 않는다.

새 선수 생성도 별도 확인 모달을 거친다. 은퇴 기록은 아카이브에 남긴다. 학생 야구·대표팀 기록을 프로 통산에 섞지 않고, 진행 중 은퇴 시 확정된 경기만 보관한다.

## 검증과 이후 개선 기준

- 320px/390px 모바일에서 가로 넘침, 버튼 접근, 상점 분리 확인.
- 키보드로 모달 열기·Tab 이동·Escape 취소·포커스 복귀 확인.
- 시즌 자동 진행이 제안에서 멈추는지, 새로고침 후 선택이 유지되는지 확인.
- 은퇴 → 5개 회고 장 → 새 선수 → 아카이브를 실제 브라우저에서 검증.

자동 검증만으로 사용 편의가 완성됐다고 판단하지 않는다. 다음 사용자 관찰에서는 ‘설명 없이 시즌 시작’, ‘현재 집중 능력 찾기’, ‘스타일 제안의 손익 이해’, ‘은퇴 취소’, ‘과거 시즌 기록 찾기’를 해보게 하고 망설인 위치를 수정한다. 새로운 메뉴 추가보다 기존 행동의 탐색 시간을 줄이는 것을 우선한다.
