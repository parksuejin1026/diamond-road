# 커리어 개편 계획

작성: 2026-11-05. 사용자 요청을 바탕으로 한 설계 초안. 아래 수치와 확률은 밸런스 검증 전 제안이며 실제 야구 규정을 뜻하지 않는다. 이번 작업은 계획 작성이며 기능 구현·배포는 하지 않는다.

## 방향과 시즌 흐름

능력치를 직접 훈련하는 게임에서, 타고난 특성·관리·감독과의 관계·돈·중요 경기로 커리어를 만드는 게임으로 바꾼다.

선수 생성(외형/포지션/특성) → 프리시즌(감독 면담/생활 관리/유료 성장) → 정규시즌 → 포스트시즌 → 국제대회(해당 연도) → 결산·수상 → 계약·병역·진로 → 다음 시즌.

일반 시즌은 자동 진행을 유지한다. 포스트시즌과 국제대회는 별도 단계로 진입한다. 매 라운드 선택을 강요하지 않는다.

## 1. 특성과 자동 성장

- 시즌 전 +2 훈련과 매년 능력치 선택 UI, 진행 차단 조건을 제거한다.
- 생성 시 특성 하나를 선택한다. 교타형/거포형/호타준족/수비형, 제구형/구위형/이닝이터 등으로 구성한다.
- 매 시즌 서로 다른 두 능력치를 특성별 가중치로 추첨한다. 예: 거포형은 파워·선구안 확률이 높고 컨택·멘탈도 등장할 수 있다.
- 두 능력치와 성장량은 시즌 시작 때 확정·저장하고 결산에서 실제 성장으로 지급한다. 재접속·화면 이동으로 재추첨할 수 없다.
- 유망주 기본 +1~3을 출발점으로 연령·잠재력·성장 여지를 반영한다. 나머지 능력치의 기존 전면 랜덤 성장은 제거하고 노화 하락은 별도로 표시한다.
- 99에 도달한 능력치는 다른 후보 우선, 가능한 능력치가 하나면 하나만 성장한다. 모든 능력치 상한이면 성장 완료를 표시한다.
- 감독이 낮은 확률로 다른 특성을 제안한다. 연간 1건 이하, 수락/유지 가능. 다음 시즌부터 적용하고 특성 변경 이력을 보관한다.

## 2. 원화 경제와 성장 구매

- salaryCR 같은 기존 금액은 버전 있는 변환으로 원화 정수 필드로 이전한다. 잠정 변환안은 기존 1CR=1만원이며 기존 연봉·옵션 규모를 먼저 점검한다.
- 보유 현금/연봉/누적 수입은 서로 분리한다. 홈에 잔액과 연봉을 표시하고 상세 장부에는 입출금 이유·연도를 기록한다.
- 무료 지원 상자를 제거한다. 개인 레슨·전문 캠프·프리미엄 코칭 같은 성장 상품으로 교체한다.
- 예시 가격: 100만원 +1, 300만원 +2, 700만원 +3. 높은 능력치에는 비용을 높이고 연간 구매 성장 총량은 +6 정도로 제한한다. 가격표는 시뮬레이션 후 조정한다.
- 성장 구매는 특성 자동 성장과 별개인 유일한 직접 능력치 투자다. 상품이 올리는 능력치를 명시한다.
- 고교는 구단 연봉 대신 제한된 육성 지원금·대회 보상을 사용한다. 유료 결제는 만들지 않는다.
- 연봉은 시즌 진행에 따라 분할 입금하고 계약금은 계약 시 한 번, 옵션·상금은 정산 시 한 번 지급한다. 조기 은퇴 시 미지급 연봉을 전액 받지 않는다.
- 기존 저장에는 확인 가능한 계약·정산 이력을 바탕으로 시작 잔액을 계산하고 변환 안내를 한 번 보여준다. 검증되지 않은 과거 수입을 중복 지급하지 않는다.
- 기존 상자 아이템은 일회 보상으로 정리하고 MVP 기념품은 수집품으로 남긴다.

## 3. 멘탈과 건강

- 영구 능력치인 정신력과 현재 상태인 멘탈을 구분한다. 건강·멘탈 상태는 각각 0~100, 기존 투수 체력 능력치와 별개다.
- 상태가 낮아져도 원래 능력치를 깎지 않고 경기 계산에서 유효 능력치에 보정한다.
- 제안 구간: 70~100 정상, 50~69 경미 저하, 30~49 뚜렷한 저하, 0~29 심각 저하. 최대 총 저하는 우선 15%로 제한한다.
- 멘탈은 선구안·제구·수비 판단 위주로 반영하고 건강은 파워·주력·구속·회복 위주로 반영한다. 정신력은 멘탈 하락을 완화한다. 중요한 상황 추가 영향은 작게 제한한다.
- 멘탈 변화 원인은 슬럼프·수상·벤치·계약 갈등·팬 반응·팀 적응 등이며 한 번의 사건으로 극단적으로 무너지지 않도록 변화량과 발생 빈도를 제한한다.
- 건강은 연령·누적 출전·생활 관리에 영향을 받는다. 첫 구현은 경기력 보정과 짧은 휴식까지만 하고 장기 부상은 후순위로 둔다.
- 무료 기본 회복을 제공한다. 식습관은 건강 유지, 취미·동료 교류는 멘탈 회복, 수면·휴식은 양쪽 소폭 회복. 전문 관리에는 현금을 사용한다.
- 시즌 전 생활 루틴을 정하면 자동 유지한다. 중간에 상태가 크게 나빠졌을 때만 선택 이벤트를 보여줘 관리 클릭을 줄인다.
- 상태 하락→부진→추가 하락의 악순환은 자동 회복·하락 제한·관리 기회로 차단한다.

## 4. 포지션과 감독

- 생성 뒤 자유 변경을 막는다. 감독 제안 또는 낮은 확률의 선수 고민 이벤트가 있을 때 변경 면담이 열린다.
- 선수 고민은 시즌당 약 5%, 감독 제안은 약 10~15%를 초기값으로 검토하되 선수 적성·구단 부족 포지션에 가중치를 둔다.
- 요청은 감독 신뢰·능력치·팀 수요에 따라 승인/시험 기용/거절로 처리한다. 거절 이유를 표시한다.
- 전환 성공 시 적응 기간을 두고 수비에 일시 보정한다. 포수 등 전문 포지션은 적응 부담을 더 크게 한다.
- 투수는 선발·불펜·마무리 보직으로 별도 처리한다. 현재 마무리·세이브·홀드 모델이 부족하므로 기록부터 확장한다.
- 투타 전향은 별도 대형 기능으로 미룬다.

## 5. 연봉·이적·배신 서사

- 매년 시즌 뒤 인상을 요구할 수 있다. 성적·출전·수상·명성·구단 예산을 고려해 수락/일부 수락/거절한다.
- 연간 요구 횟수를 제한한다. 다년계약 중에도 요구는 가능하지만 보장 계약은 일방적으로 바꾸지 않고 구단이 동의하는 재협상으로 처리한다.
- 기존 FA·트레이드·방출·재입단을 확장한다. 비FA 선수가 원하는 팀과 바로 계약하는 기능은 만들지 않는다.
- 트레이드는 실제 계약·선수단 이동과 연결하고 이전 소속 기록을 보존한다. 기본 빈도는 낮게, 벤치·구단 부진·리빌딩에 가중치를 둔다.
- 구단 주도 통보/선수 이적 요청/협상 가능한 제안을 구분한다. 모든 트레이드에 무조건 거부권을 주지 않는다.
- 배신 이적은 오랜 소속·팬 애정이 높은 선수가 자발적으로 라이벌 FA 이적을 택했을 때 발생하는 팬 반응 서사다. 강제 트레이드를 배신으로 취급하지 않는다.
- 친정 방문 야유·첫 안타/홈런 반응·재회 이벤트를 추가하고 영구결번 심사에도 팀별 관계를 반영한다.

## 6. 결산·수상

- 정규시즌 MVP와 포지션별 골든글러브를 판정하고 획득/미획득을 모두 명시한다. 포스트시즌 MVP는 별개다.
- 골든글러브는 수비상과 구분한다. 투수 1명·포수·내야 각 1명·외야 3명·지명타자로 구성하고 출장 자격과 포지션별 성과를 반영한다.
- 개인 수비 기록과 포지션별 출전/수비 이닝을 먼저 추가한다. 같은 선수가 여러 포지션 수상 후보로 중복 등록되지 않게 한다.
- 총평은 실제 기록으로 2~3문장을 생성한다. 전년 변화·성장·팀 성적·주요 사건을 연결하며 표본이 적으면 과장하지 않는다.
- 결산 순서: 시즌 총평 → 개인/팀 기록 → 두 능력치 성장 → 수상 → 현금 정산 → 진로.

## 7. 포스트시즌과 도트 연출

- 정규시즌 종료 즉시 결산하는 경로에서 포스트시즌 관전 상태를 분리하고, 시리즈 대진·승수·개인 기록을 따로 보관한다.
- 타석 전후 주자·점수·이닝·아웃·타자·투수·실제 수비수를 이벤트로 저장한다. 이 결과를 연출이 소비한다.
- 첫 연출 묶음: 홈런, 다이빙 캐치, 끝내기, 우승. 이후 담장 캐치·슬라이딩 캐치·송구·투수 삼진을 확장한다.
- 홈런: 타격 프레임 → 임팩트 정지 → 카메라 이동 → 포물선 → 관중 반응 → 베이스 러닝. 호수비: 타구 추적 → 전력 질주 → 점프/다이빙 → 포구 → 착지·환호.
- 9회말 2아웃 역전 끝내기 만루홈런은 해당 조건이 실제로 성립할 때만 특별 연출한다. 일어나지 않은 결과를 삽입하지 않는다.
- 희귀 명장면은 개발용 재생 화면에서 모든 조건을 검증한다. 게임 플레이 결과를 강제로 고정하는 옵션으로 노출하지 않는다.
- 재생은 기록을 다시 적용하지 않는다. 건너뛰기·빠르게 보기·모션 줄이기·새로고침 복원을 지원한다.
- 현재 팀 평균 기반 수비 판정을 실제 수비수의 관여 이벤트로 확장해야 호수비 주인공과 기록이 일치한다.

## 8. 국제대회와 병역

- 기존 아시안게임을 재사용하고 세계 야구 대회를 추가한다. 세계대회 우승은 명성·상금·커리어 성과로 연결한다.
- 현행 제도에 맞추면 세계대회 우승 자체는 병역 혜택 조건으로 설정하지 않는다. 아시안게임 금메달 등 해당 조건과 실제 출전 여부를 별도로 확인한다.
- 화면에는 군면제 대신 체육요원 편입으로 표시한다. 해당 복무 의무는 간소화 상태로 관리한다.
- 미해결 선수는 상무 지원 선택을 제공하고 나이·성적·보직·자리 경쟁으로 합격/탈락을 결정한다. 상무가 자동 입단하는 곳이 되지 않게 한다.
- 탈락 시 재지원/일반 복무 경로를 제공한다. 복무 기간은 월 단위 시간으로 관리해 시즌 정수 두 번과 무조건 같게 처리하지 않는다.
- 상무 기록은 퓨처스 기록으로 분리한다. 나이는 정상 증가하고 보유권·계약·FA 등록일 계산·급여 중단/복귀 처리를 함께 설계한다.
- 국제대회 일정은 데이터로 관리한다. 올림픽 야구는 매 대회 개최를 가정하지 않는다.

## 9. 은퇴·실존 선수 비교·영구결번

- 홈과 선수 탭에 은퇴하기를 추가한다. 현재 시즌 진행 중이면 이미 확정된 경기까지만 정산하고 이중 확인 후 종료한다. 관전 중에는 경기 확정 후 처리한다.
- 기록 삭제 대신 은퇴 커리어를 아카이브한다. 새 선수 생성과 과거 선수 회고를 함께 지원한다.
- 은퇴 회고는 선수 유형·전성기·대표 구단·우승·국가대표·부침·누적 수입을 실제 이력으로 설명한다.
- KBO 은퇴 선수의 검증된 공개 성적을 타자/선발/불펜으로 구분한 비교 데이터로 만든다. 출처·조회일·집계 범위를 남긴다.
- 누적량/경기당 생산성/장타·출루/전성기/수상/팀 충성도 등을 정규화해 유사도 상위 3명을 산출한다. 시대 차이와 표본 수를 보정하고 자체 지표임을 밝힌다.
- 기록에 없는 능력치를 추측해 비교하지 않는다. 초단기 커리어는 비교 불충분으로 표시한다. 임의 퍼센트를 붙이지 않는다.
- 등번호와 팀별 사용·결번 목록을 먼저 도입한다. 영구결번은 장기 소속·구단 누적 기여·수상·우승·팬 관계를 기준으로 판정한다. 개인 MVP 횟수만으로 자동 지급하지 않는다.

## 10. 선수 외형

- 얼굴·피부·머리·수염·체형·타격 자세·투구 폼·장비를 조합한다. 첫 목표는 각각 구별되는 기본 외형 12종과 타격 3종/투구 3종이다.
- 생성 화면 프리뷰와 경기/프로필/은퇴 화면에 동일한 외형 ID를 사용한다. 구단별 유니폼·등번호와 연령에 따른 외형 변화를 반영한다.
- 도트 스프라이트 규격·프레임·팔레트를 먼저 고정해 애니메이션 자산을 공유한다. 기존 SVG는 UI/프리뷰에 활용하고 경기 액션은 스프라이트 아틀라스를 검토한다.

## 구현 순서와 완료 조건

1. **저장·경제·성장 기반:** 원화 장부, 특성, 두 능력치 성장, 무료 훈련/상자 제거, 기존 저장 이전. 고교·프로·은퇴 저장이 열리고 재접속 중복 지급·추첨이 없어야 한다.
2. **관리·면담·계약:** 멘탈/건강, 생활 루틴, 포지션 면담, 매년 재협상, 이적 서사. 거절·부진 상황에서도 다음 시즌 진행이 가능해야 한다.
3. **기록·결산:** 포지션 출장/수비 기록, 골든글러브, MVP 표시, 총평, 현금 정산. 원래 경기 기록과 결산 합계가 맞아야 한다.
4. **경기 연출:** 이벤트 기록과 포스트시즌 상태 분리 → 홈런/호수비/끝내기/우승 → 외형 다양화. 연출 중 중단·스킵·복원이 기록을 바꾸지 않아야 한다.
5. **국제대회·병역:** 세계대회, 아시안게임 출전 조건, 상무/일반 복무, 복귀. 병역 분기별 계약·나이·급여·FA 계산이 맞아야 한다.
6. **커리어 유산:** 은퇴 아카이브, 실존 선수 비교, 영구결번, 팀별 회고. 비교 데이터와 판정 근거를 추적할 수 있어야 한다.
7. **통합 검증·배포:** 타자/투수/불펜 전 생애 시뮬레이션, 복수 육성/소비 전략, 무현금 회복, 모바일·키보드·모션 줄이기 검증 후 GitHub Pages 배포.

기존 MVP 12회 목표는 우선 유지하되 새 경제·성장 체계에서 달성 가능성을 재측정한다. 단계별 플레이 가능한 배포를 권장한다.
