# 성장·상점·외형·고교 커리어 개편

> 2026-11-06: 집중 육성·외형·계약·국제대회·대학 진학의 최신 구현은 [CAREER_DECISIONS_UPDATE.md](CAREER_DECISIONS_UPDATE.md)를 따른다. 아래 내용은 이전 작업 기록이다.


2026-11-05. 최신 사용자 요청이 이전 개편 문서의 생활 관리·코칭·시작 지원금 설계보다 우선한다.

## 확정한 변경과 구현

1. **삭제:** 신규 커리어 시작 지원금, 매년 고교 육성 지원금, 생활 루틴 선택, 시즌 전 무료 회복 버튼, 능력치 직접 선택 코칭, 현금 입출금 내역 UI. 신규 선수 현금은 0원이다. 과거 저장의 실제 잔액과 이미 반영한 능력치는 보존한다.
2. **자동 성장:** 처음 고른 플레이스타일에 가중치를 둔 서로 다른 두 능력치가 매년 성장한다. 구매와 별개이며 직접 성장 능력치를 고르는 기능은 없다. 이전에 요청한 감독의 스타일 전환 제안은 유지한다.
3. **아이템 상점:** 사용자 확인에 따라 매 시즌 무작위 3종 입고, 그중 1개 구매. 역할별로 사용할 수 있는 상품 30종을 구성했다. 상품마다 가격과 상승 능력치가 다르다. 구매 즉시 실제 능력치와 잔액에 반영하고 해당 시즌의 추가 구매를 막는다. 재접속으로 상품을 바꾸거나 중복 적용할 수 없다. 보유 아이템에서 구매 연도와 실제 상승량을 볼 수 있다.
4. **외형:** 기존 숫자 드롭다운과 단순 SVG 캐릭터 대신 새 캐릭터 이미지 6종을 선택하는 카드 UI. 얼굴·헤어·체형·장비·자세를 각각 새로 만들었다. 선택한 이미지를 미리보기·홈·선수·명장면·드래프트·은퇴 화면에 연결했다. 응원 구단 선택과 구단 마크 기능은 유지한다.
5. **드래프트:** 실제 저장된 라운드와 전체 지명 순번을 크게 표시한다. 구단 로고 등장 → 선택한 선수와 가족 등장 → 구단명 공개·축하 효과가 이어지는 전용 화면이다. 건너뛰기와 모션 줄이기를 지원한다. 미지명은 육성선수 제안으로 구분하고 지명된 것처럼 표시하지 않는다.
6. **학생 수상·커리어:** 고교 전국대회마다 실제 출전 기록으로 대회 MVP·타격상·타점상·우수투수상을 선정한다. MVP는 실제 출전한 우승팀 선수 중에서 선정한다. 본인의 우승과 개인상을 고교 학년별 이력·시즌 총평·기록 탭·은퇴 연대기에 남긴다. 주말리그와 전국대회 성적을 합친 시즌 총평을 보여준다.

## 현금과 고교 성과

시작·정기 지원금은 없다. 프로 연봉·계약금·옵션·대회 성과로 얻는 돈을 사용한다. 게임에서 고교 대회 우승은 50만원, 개인상은 35만원의 성과 상금으로 계산한다. 이는 실제 대회 상금 규정을 재현한 수치가 아니다. 성과가 없으면 고교 시즌 종료 시 지급액도 0원이다. 같은 학년 결산을 반복해도 수상·상금을 중복 반영하지 않는다.

## 이미지 제작

built-in `image_gen`으로 새 캐릭터 6종과 가족 레이어 1종을 각각 생성했다. 원본의 투명 알파를 보존해 `public/art/players/`와 `public/art/scenes/draft-family.png`에 저장했다. 캐릭터를 단순한 색상 변경으로 구성하지 않았다. 이 이미지들은 큰 원화형 도트풍 이미지이며 프레임별 손그림 스프라이트 시트를 뜻하지 않는다. 드래프트의 등장·환호·축하 움직임은 레이어와 CSS로 구현한다.

프롬프트 세트는 [ART_PROMPTS.md](ART_PROMPTS.md), 아이템 아이콘의 원본 코드는 `src/components/pixel/EquipmentIcon.tsx`다. 기존 SVG 아이콘 체계에 맞춰 장비 종류별 픽셀 형태를 제작했다.

## 검증

엔진/저장 테스트 80개, Chromium 화면 시나리오 24개, 타입 검사와 `/diamond-road` 정적 빌드를 통과했다. 추가 검사는 지원금 0원, 상품 3종·연간 1회 구매·재접속 유지, 이미지 외형 선택, 실제 지명 순번·구단·가족 화면, 고교 수상 보관, 중복 결산 방지를 포함한다.

고교 개인상은 실제 게임 기록을 쓰는 간소화 점수 모델이며 실제 주최 측의 투표·후보 자격 전체를 재현하지 않는다. 이전 저장에 개인상 원시 기록이 없으면 새 수상을 만들어 넣지 않는다.
