# 커리어 개편 구현 기록

2026-11-05. [설계 초안](CAREER_REWORK_PLAN.md)에 따른 구현. 로컬 검증 완료. 공개 버전은 이 변경이 포함된 main 커밋의 GitHub Actions 배포 성공 여부를 기준으로 한다.

## 구현한 기능

- 시즌 전 직접 +2 훈련·필수 선택·무료 상자 UI 제거. 시작 스타일에 가중치를 둔 서로 다른 두 능력치 자동 성장, 감독 면담을 통한 스타일 변경.
- 원화 현금 잔액, 연봉 분할 지급, 계약금·옵션·상금 입금, 입출금 장부, 가격별 개인 코칭과 연간 +6 한도. 기존 CR 숫자는 저장 호환을 위해 내부에서만 유지하며 표시·현금 장부는 1CR=1만원으로 변환한다.
- 현재 멘탈·건강과 영구 정신력·투수 체력을 구분. 슬럼프·팀 연패·연령·생활 루틴이 상태에 영향을 주고 경기의 유효 능력치에 최대 15% 보정. 식습관·취미·휴식 루틴과 연간 무료 회복.
- 생성 이후 자유 포지션 변경 제거. 감독 제안 또는 드문 선수 고민으로 면담, 요청 거절, 전환 시즌 수비 적응 보정.
- 매년 한 번 연봉 인상 요구와 수락/거절. 기존 계약 제안별 명성 협상은 유지. 오랜 소속에서 자발적으로 FA 이적하면 팬 반발과 멘탈 변화, 강제 트레이드는 별개.
- 정규시즌 MVP 및 포지션별 골든글러브 판정, 수상/미수상 표시, 실제 기록으로 생성하는 짧은 시즌 총평.
- 정규시즌 후 별도 포스트시즌 진입 화면. 실제 타석 상태와 실제 수비 관여자를 기록해 홈런·호수비·삼진·끝내기·우승 장면을 재생. 희귀한 끝내기 만루홈런은 실제 조건을 만족할 때만 판정. 재생은 경기 기록을 바꾸지 않는다.
- 기존 아시안게임과 별도의 8개국 세계대회. 세계대회는 2027년부터 4년 주기, 가상 토너먼트로 실제 타석 엔진을 사용한다. 세계대회 우승은 병역 혜택과 연결하지 않는다.
- 아시안게임 금메달과 실제 출전 시 체육요원 상태. 상무 선발 합격/탈락, 일반 복무, 18개월 복무 후 원소속팀 복귀. 상무 성적은 별도 보관하며 KBO 누적 기록·FA 등록일·연봉에 합산하지 않는다.
- 홈·선수 탭 은퇴, 부분 시즌 프로 기록 보존, IndexedDB 은퇴 아카이브. 새 선수 생성 시 과거 은퇴 기록 유지.
- 검증한 KBO 은퇴 선수 12명(타자 6명·투수 6명)의 통산 기록을 사용하는 유사도 상위 3명. 일정 출전 미만은 비교 불충분 표시. 장기 소속·수상·우승·팬 관계에 따른 영구결번 판정.
- 12개 외형 조합, 피부·머리·수염·유니폼·장비·등번호 디테일. 구장 관중·조명·광고판·덕아웃·타석 디테일 보강.
- KBO 공식 홈페이지가 참조하는 10개 구단 마크를 로컬 PNG로 보관하고 구단 선택·홈·순위표·계약에 표시. 로딩 실패 시 약칭 표시. 자체 야구 다이아몬드 SVG 파비콘.

## 검증 기록

- 최종 엔진/저장 테스트 76개 통과. 상무·일반 복무, 부분 시즌 은퇴도 포함한다.
- GitHub Pages 하위 경로 `/diamond-road` 정적 빌드 통과.
- Chromium 화면 시나리오 19개 통과. 생성·현금 구매·생활 루틴·은퇴 아카이브·계약·트레이드·구단 마크 10개·파비콘·끝내기 연출·모션 줄이기·이전 저장 복원을 포함한다.
- 320px 홈과 1280px 명장면 화면을 이미지로 확인하고 가시성과 연출 높이를 추가 조정했다.
- 장기 검사 14개 통과(553.77초): 100개 시드 첫 프로 시즌, 타자/투수 기본 커리어 2개, 현금·자동 육성 커리어 10개, MVP 도전 커리어 1개. 각각 38세까지 진행했다. 이후 코칭 묶음 가격과 상태 변화량을 조정하고 엔진/화면 검사를 다시 통과했다.
- 10개 육성 표본의 최고 OVR은 76~85, MVP는 0~4회였다. 별도 도전 표본은 2회였다. 개편 전 12회 달성 결과를 새 방식의 달성 증거로 재사용하지 않는다.

## 게임에서 간소화한 범위

- 골든글러브는 출장 기준과 포지션별 기록 점수로 선정한다. 실제 기자 투표나 실제 후보 자격 규정 전체를 재현하지 않는다.
- 세계대회는 실제 WBC 대진·브랜드·참가국 편성을 그대로 재현하는 기능이 아니다. 올림픽 야구 대회는 추가하지 않았다.
- 복무는 시즌 단위 진행에 맞춰 18개월을 처리한 뒤 다음 프리시즌으로 복귀하므로 두 시즌이 비게 된다. 상무 성적은 60경기 가상 평가 표본이며 전체 퓨처스 구단·일정을 구현한 것은 아니다. 봉사·훈련 등의 세부 의무는 상태 설명으로 간소화한다.
- 투수 보직은 기존 구원/선발 모델을 유지한다. 마무리 전문 보직·세이브·홀드는 아직 별도 기능으로 구현하지 않았다.
- 실존 선수 유사도는 생산성과 누적 출전을 비교하는 게임 자체 지표다. 시대 보정·해외 기록·실제 선수 성격·수비 능력 추정은 포함하지 않는다. 비교 표본은 각 역할 6명이며 전체 KBO 은퇴 선수를 망라하지 않는다.
- 영구결번은 게임 커리어에 대한 판정이며 실제 구단의 기존 결번 목록·선수단 전체 등번호 충돌은 모델링하지 않는다.
- 도트 외형은 하나의 새 기본 형태에 피부·머리·수염 등을 조합한 12종이다. 서로 다른 체형 12개나 자세별 스프라이트 아틀라스를 뜻하지 않는다. 연출은 SVG 캐릭터와 CSS 키프레임을 사용한다.
- 개편 후 MVP 12회 목표는 유지한다. 새 성장·경제 방식에서 달성이 보장되는 것으로 주장하지 않는다.
