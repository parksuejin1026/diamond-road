# 2026-11-04 플레이 확인 및 수정

## 참고 게임 직접 플레이

[벤치에서 발롱까지](https://kickru.com/)에서 신규 브라우저로 공지·설문을 닫고 아바타 → 이름·학교·포지션 → 스타일 후보 → 집중 육성 → 고1 첫 시즌 → 시즌 결산까지 실제 버튼으로 진행했다. 랭킹 등록이나 설문 전송은 수행하지 않았다. 참고 화면은 로컬 `artifacts/reference/`에만 보관하며 게임 자산으로 사용하지 않는다.

확인한 핵심은 16세 학생으로 출발하는 시간의 흐름, 비슷한 종합 능력치에서 개성을 고르는 생성 과정, 출전 기회와 성장의 연결, 학년별 대회 결과, 성장 전후를 비교하는 결산이었다. 이전 구현은 이 흐름 없이 곧바로 18세 프로 선수를 생성했고 큰 소개 문구가 매 시즌 반복됐다.

이번 변경에서는 실제 고교/U18 선택, OVR 45의 3가지 역할별 스타일, 집중 육성, 감독 신뢰도와 벤치→주전 경쟁, 3학년 졸업 후 드래프트, 고교 성적과 프로 성적의 분리, 성장 전후 비교와 독자적인 시즌 리포트를 구현했다. 생성 이후에는 큰 소개 영역을 제거했다. 참고 게임의 화면·문구·이미지·코드는 가져오지 않았다.

## 학교·구단 데이터 확인

- [KBSA 2026년 18세 이하부 팀정보](https://www.korea-baseball.com/info/team/team_list?kind_cd=31&season=2026): 4페이지의 104팀을 확인하고 등록 ID·팀명·지역만 게임 데이터에 반영했다. 고교와 U18 클럽을 모두 포함한다. 선수·코치 명단은 게임 데이터로 수집하지 않았다.
- [KBO 공식 구단 소개](https://www.koreabaseball.com/kbo/league/teaminfo.aspx): 실제 10구단의 명칭을 반영했다.
- [KBO 공식 경기운영체제](https://www.koreabaseball.com/Kbo/League/GameManageRule/GameManage.aspx): 팀당 144경기·상대별 16경기와 5팀 포스트시즌 구조를 확인했다.

고교 대진은 104팀을 지역순으로 묶은 13개 게임 권역, 권역별 홈·원정 14경기다. 전국대회는 등록된 모든 팀을 사용하는 게임 내 토너먼트이며 실제 대회의 참가 자격·일정·투구 제한 전체를 재현한 것은 아니다. 선수 능력치·드래프트·경기 결과는 가상 데이터다.

## 우리 게임의 검증 범위

- 새 브라우저에서 고교 검색 → 16세 생성 → 훈련 → 주말리그와 이벤트 → 성장 결산 → 2·3학년 → 드래프트 → 19세 KBO 입단 → 새로고침을 실제 UI로 진행하는 E2E를 추가했다. 이 시나리오는 저장 파일을 주입해 학년을 건너뛰지 않는다.
- 별도 타자·투수 미니게임 시나리오로 직접 조작, 중복 기록 방지와 경기 재개를 검증한다.
- 단위·통합 검사에서 104팀 전원의 대진과 로스터, 고교 3년·전국대회·드래프트·프로 첫 시즌, 기존 8구단 저장 호환을 검증한다.
- 스트레스 검사는 100개 프로 커리어의 첫 시즌과, 타자·투수 각각 16~38세의 고교 3년+프로 20시즌을 검사한다.

자동 브라우저 조작을 통한 플레이 확인이며, 일반 사용자 대상 재미 검증을 완료했다는 의미는 아니다.
