# 커리어 선택 화면·대학 진학·캐릭터 모션 개편

2026-11-06. 이번 사용자 지시가 이전 개편 초안의 자동 계약·집중 능력치 선택 금지보다 우선한다.

## 반영한 동작

- 선수 생성에서 역할에 맞는 집중 능력치를 직접 고른다. 선택한 능력치와 특성 가중치로 뽑은 보조 능력치가 성장한다. 시즌 준비 때 매년 한 번 현재 능력치를 제외한 후보로 랜덤 변경할 수 있다. 결과와 사용 연도를 저장해 재접속으로 다시 추첨하지 않는다.
- 정지 원화 대신 약 3등신의 코드 기반 픽셀 캐릭터를 사용한다. 얼굴·머리·피부 외형 6종, 팔·다리·몸통·배트·글러브를 분리했다. 대기 호흡, 타격의 준비·스텝·스윙·주루, 투구의 다리 들기·릴리스·팔로스루, 다이빙 캐치, 우승 점프를 구현했다. 기존 PNG 원본은 보존했다.
- 포스트시즌 명장면은 본인 행동만 기록하고 끝내기·만루 등 중요도를 반영해 한 장면을 고른다. 다른 선수에게 본인 외형을 씌우지 않는다. 전용 화면에서 자동 재생·재생 다시 보기·확인 후 진행을 제공한다. 해당 행동이 없으면 장면을 만들어내지 않는다. 기록 화면에서 그해 명장면을 다시 열 수 있다.
- 구단과 계약하는 **모든 경우**에 전용 화면을 표시한다. 신인·육성 입단, 연봉 재계약, 비FA 다년계약, FA 잔류·이적, 방출 후 입단, 트레이드가 대상이다. 신인 계약은 드래프트 결과 → 입단 계약 조건 → 직접 체결 순서다. 기존 소속팀 제안도 자동 수락하지 않는다. 연봉 인상 수락 역시 제안으로 표시하고 서명 전 계약을 변경하지 않는다.
- 세계대회·아시안게임은 선발 도전/보류 → 대회 결과 확인으로 나눈다. 보류한 선수에게 개인 기록·선발 보상·병역 혜택을 주지 않는다. 감독 면담, 이전 저장의 선택 이벤트, 병역 진로와 결과도 전용 화면에서 처리한다. 선택과 확인 상태는 저장된다.
- 고교 졸업에서 바로 프로 도전 또는 등록 대학 50팀 중 진학을 선택한다. 대학은 1~4학년, 연간 14라운드 리그, 대학 선수권·왕중왕전으로 구성한다. 4학년 뒤 드래프트, 다음 해 23세 프로 입단으로 이어진다. 학생 기간의 프로 연봉·FA 등록일을 적립하지 않는다. 고교/대학별 소속·성적·수상·성장 이력을 보존한다.

## 진행 구조

일반 시즌 자동 진행 → 포스트시즌 시작 선택 → 본인 명장면 1개(존재할 때) → 해당 연도 국제대회 참가 선택·결과 확인 → 구단 계약 선택 → 시즌 결산/다음 시즌.

고교 졸업은 별도 진로 화면에서 대학 또는 드래프트를 고른다. 일반 홈·기록·상점 화면에 이벤트 선택 화면을 함께 쌓지 않는다. 이벤트 도중 새로고침해도 미결정 상태를 유지한다.

## 검증

최종 결과는 [HANDOFF.md](HANDOFF.md)에 기록한다. 대학 경로는 타자와 투수 모두 졸업·저장 복구·드래프트·프로 입단까지 검사한다. 계약 유형별 전용 화면, 국제대회 선택 대기, 본인 명장면의 실제 자세 변화, 모바일 외형·계약 화면을 브라우저에서 검사한다.
