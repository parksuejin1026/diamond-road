# DIAMOND ROAD

야구선수 커리어 게임. 기준 문서: [MVP 명세서](DIAMOND_ROAD_MVP_SPEC.md).

**[게임 플레이](https://parksuejin1026.github.io/diamond-road/)** · GitHub Pages

## 실행

Node.js 22 이상을 권장합니다. GitHub Actions에서는 Node.js 22를 사용합니다.

```sh
npm install
npm run dev
```

http://localhost:3000 에서 실제 고교·U18 야구부를 검색해 16세 선수로 시작합니다. 고교 3년 동안 벤치에서 주전 기회를 얻고, 주말리그·전국대회와 집중 육성을 거쳐 신인 드래프트에 참가합니다. 졸업 후 19세에 KBO에 입단해 38세까지 프로 커리어를 이어갑니다. 중요한 타석·투구는 직접 플레이하거나 자동으로 넘길 수 있습니다.

저장은 매 라운드·중요 상황·선택 후 IndexedDB에 기록됩니다. 새로고침하면 저장된 지점에서 계속하고, 미니게임은 해당 타석의 처음부터 재개합니다. 최근 저장이 손상되면 직전 저장으로 복구하고 안내합니다. 계정·서버·별도 DB는 필요하지 않습니다.

```sh
npm test
npm run typecheck
npm run build
npm start
```

빌드 결과는 `out/`이며 `npm start`로 http://127.0.0.1:4173 에서 정적 빌드를 확인할 수 있습니다.

## GitHub Pages 배포

1. 프로젝트 파일을 GitHub 저장소의 `main` 브랜치에 올립니다. `node_modules/`, `.next/`, `out/`는 올리지 않습니다.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 선택합니다.
3. `main`에 push하거나 Actions의 **Deploy GitHub Pages**를 수동 실행합니다.

[배포 워크플로](.github/workflows/pages.yml)가 `npm ci` → 단위 테스트 → 정적 빌드 → Chromium 브라우저 테스트 → Pages 배포를 수행합니다. Pages 설정에서 전달받은 `base_path`를 사용하므로 프로젝트 저장소의 `/저장소명/`과 사용자 홈페이지 루트 경로를 모두 지원합니다.

프로젝트 경로를 로컬에서 확인하려면 PowerShell에서 다음과 같이 실행합니다.

```powershell
$env:NEXT_PUBLIC_BASE_PATH='/diamond-road'
npm run build
npm start
```

이때 주소는 http://127.0.0.1:4173/diamond-road/ 입니다. 기본 경로로 돌아가려면 `$env:NEXT_PUBLIC_BASE_PATH=''`로 설정한 뒤 다시 빌드합니다. 브라우저 저장은 사용한 도메인에 귀속되므로 localhost와 배포 사이트 사이에 자동으로 옮겨지지 않습니다.

## 게임 규칙과 현재 한계

벤치 타자는 7회 이후 타순 한 자리에 교체 출전합니다. 고교 투수는 벤치에서 불펜 출전으로 시작해 신뢰도를 쌓으면 선발 기회를 얻습니다. 고교는 3인, 프로는 5인 선발 로테이션을 사용합니다. 선발은 95구 또는 6회 종료 후 교체하며 불펜은 25구를 기준으로 교체합니다. 불펜 세 명을 모두 사용하면 마지막 투수가 끝까지 던집니다. 구원승은 최종 역전 시점의 투수에게 부여하고, 해당 투수가 5이닝 미만 선발이면 경기 종료 시점 투수에게 부여하는 간소화 규칙입니다. 포스트시즌도 12회 종료 규칙을 사용하고, 와일드카드 외 무승부는 다시 경기합니다. 정규 시즌 순위 동률은 승수와 구단 ID로 결정합니다.

학교·구단 명칭은 실제지만 선수·능력치·경기·드래프트는 가상입니다. 고교 권역 편성, 전국대회 참가 자격과 일정, 학생 투구 제한 전체를 실제 규정대로 재현한 것은 아닙니다. 고교/U18 시작을 지원하며 초등·중등·대학 단계는 구현 범위에 포함하지 않았습니다. [데이터 출처와 직접 플레이 기록](docs/PLAYTEST_NOTES.md)을 참고하세요.

기존 8구단 저장은 구단명과 ID를 변환하며 현재 시즌의 경기·기록을 보존합니다. 그 시즌은 기존 대진으로 마치고 다음 시즌부터 10구단·144경기로 확장됩니다. 진행 중인 기존 프로 선수를 강제로 16세로 되돌리지 않습니다. 고교 시작은 새 커리어에 적용됩니다.

미니게임 투구 속도와 확률은 프로토타입 밸런스 값입니다. 실제 야구 통계를 재현한 모델은 아닙니다. 2군 성적은 육성 경기 수로 추상화합니다. NPC는 시즌 간 성장·하락하며 38세 이후 가상 신인 능력치로 교체됩니다. P1의 공유 이미지 카드·음악·효과음은 미구현입니다. 일반 사용자 5명 대상 재미 검증, 실제 모바일 기기와 Safari·Firefox 수동 검증은 아직 진행하지 않았습니다.
