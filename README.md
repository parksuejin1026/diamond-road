# DIAMOND ROAD

**[게임 플레이](https://parksuejin1026.github.io/diamond-road/)** · GitHub Pages

16세 학교 야구부의 벤치에서 시작해 드래프트, KBO, 국가대표, 은퇴까지 이어가는 야구 선수 커리어 게임입니다. 시즌은 한 번에 자동 진행합니다. 현재 코드의 구현을 설명하며, 공개 버전은 main의 최근 성공한 배포를 기준으로 합니다.

## 실행

Node.js 22 이상에서 npm install 후 npm run dev로 실행합니다. 개발 주소는 http://localhost:3000 입니다.

- npm test: 엔진·저장·진행 규칙 검사
- npm run typecheck: TypeScript 검사
- npm run build: out/ 정적 내보내기
- npm start: http://127.0.0.1:4173 정적 빌드 미리보기
- npx playwright test: 실제 브라우저 검사
- npm run test:stress: 100개 첫 시즌·타자/투수 장기 커리어·10개 육성 커리어·MVP 12회 빌드 검사

## 플레이 흐름

1. 생성 3단계에서 이름·역할, 학교·포지션·성장 특성, 외형·등번호를 정합니다. 이전 단계로 돌아가도 선택이 유지됩니다.
2. 특성에 따라 매년 두 능력이 자동 성장합니다. 생활 루틴으로 건강과 멘탈을 관리하고, 모은 현금으로 개인 코칭을 구매합니다. 시즌 전 필수 훈련과 무료 상자는 없습니다.
3. 시즌을 자동 진행하고 프로에서는 포스트시즌으로 별도 진입합니다. 실제 경기의 도트 명장면, 짧은 총평, MVP·골든글러브 수상 여부와 현금 정산을 확인합니다.
4. 고교 3년 후 드래프트로 입단하고 프로에서는 재계약·FA·다년계약·트레이드·방출 후 재입단을 선택합니다.
5. 감독 면담에서 성장 특성·포지션 전환을 논의하고 매년 연봉 인상을 요구할 수 있습니다. 국제대회·병역·상무 경로를 선택하고, 홈·선수 탭에서 언제든 은퇴해 회고와 실존 선수 유사도를 확인합니다. 38세 시즌 종료 후에는 자동 은퇴하며 기록은 아카이브에 남습니다.

홈·시즌·선수·기록 하단 탭으로 이동합니다. 시즌은 요약·대회·진로, 기록은 리그·커리어·대표팀으로 나눴습니다. 홈에는 현금·멘탈·건강을 표시하고 긴 관리·기록 화면은 펼침 영역과 내부 스크롤로 확인합니다. 시즌 MVP 12회 목표와 전설 칭호·기념품도 유지합니다.

## 구현

- 실제 KBO 10구단과 가상 선수단, 팀당 144경기·총 720경기.
- KBSA 등록 고교/U18 104팀, 지역·이름 검색과 페이지 선택. 게임 속 14경기 권역 리그와 4개 전국대회.
- 타자 9포지션과 수비 반영, 타격 능력에 따른 타순. 지명타자는 수비에서 제외됩니다.
- 투수는 구원에서 시작해 능력·성적으로 선발 기회를 얻습니다. 체력이 실제 선발 투구 한도에 반영되고 불펜 등판 순서는 순환합니다.
- 특성 기반 두 능력치 성장·노화, 원화 현금 장부와 가격별 코칭, 생활 루틴·멘탈·건강, MVP 보상 중복 방지.
- KBO 정규 기록과 분리한 아시안게임 선발·조별리그·슈퍼라운드·메달전·개인 기록.
- 보류권을 반영한 연봉 재계약, FA 취득·유보·재취득, 비FA 다년계약, 트레이드, 방출 후 입단, 성적 옵션 정산.
- 세계 야구 대회, 아시안게임 성과에 따른 체육요원, 상무 지원·일반 복무·복귀 경로.
- 소속·성적·수상·최고 시즌을 돌아보는 은퇴 회고, 은퇴 기록 보관·실존 선수 비교·영구결번 판정.
- 직접 제작한 픽셀 구장·선수·메달·아이템 SVG와 SIL OFL 한글 Galmuri 글꼴.
- 매 라운드·선택 후 IndexedDB 자동 저장, 직전 저장 복구, 이전 8구단·수동 경기 중단 저장 호환.

## 규칙과 한계

실제 경기 통계나 KBO 규약 전체를 재현한 모델은 아닙니다. 18인 가상 선수단과 간소화한 수비·교체·승패 규칙을 사용합니다. 소규모 불펜의 과다 이닝이 MVP 점수를 왜곡하지 않도록 순수 구원투수의 수상용 기여량을 보정하며 원래 기록은 바꾸지 않습니다. 수상 지수는 게임용이며 WAR가 아닙니다.

건강과 현재 멘탈은 경기의 유효 능력치에 영향을 주며 원래 능력치는 보존합니다. 피로는 이전 저장 호환용입니다. 금액은 원화로 표시하며 실제 돈과 연결하지 않습니다. 이전 CR 계약 숫자는 1CR=1만원으로 변환하고 확인 가능한 과거 정산을 잔액으로 이전합니다.

국제대회·병역·계약·실존 선수 비교의 간소화 범위는 개편 보고서를 참고하세요. FA 보상선수·샐러리캡·마무리 전문 보직 등은 전체 규정을 재현하지 않습니다. 일반 사용자 대상 재미 조사, 실제 모바일 기기 및 Safari·Firefox 수동 검사는 별도 과제입니다.

## 배포

main push 시 GitHub Actions가 설치·테스트·정적 빌드·Chromium 검사를 마친 뒤 Pages에 게시합니다. base_path를 사용하므로 저장소 하위 경로도 지원합니다. PowerShell에서는 $env:NEXT_PUBLIC_BASE_PATH='/diamond-road' 설정 후 빌드·실행하여 배포 경로를 확인할 수 있습니다. 기본 경로는 환경변수를 비운 뒤 다시 빌드합니다.

저장은 사용한 브라우저·도메인에 귀속됩니다. localhost와 공개 사이트의 저장은 자동으로 공유되지 않습니다. node_modules/·out/·테스트 원시 기록은 저장소에 올리지 않습니다.
